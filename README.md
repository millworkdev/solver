# millworkdev/solver

Public publishing repository for the npm package
[`@millwork/solver`](https://www.npmjs.com/package/@millwork/solver).

This repository holds a **curated export** of exactly what ships to the npm
registry, plus the pinned publishing workflow. The canonical engineering
source (SDK source code, tests, CI) lives in a separate **private**
repository; this repository is not a mirror of it and does not accept source
contributions.

**No issues or support here.** Issues and support requests opened against
this repository are not monitored. Support for `@millwork/solver` follows the
package's documented support route: a sanitized support report (Problem
`type`, `status`, `instance`, and `retryAfterS` only — never API keys,
credentials, task content, or private paths), per the package documentation.
