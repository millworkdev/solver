# Support

Start with the [Millwork documentation](https://docs.getmillwork.dev).

For non-sensitive package, configuration, or compatibility problems, open an
[issue](https://github.com/millworkdev/solver/issues). Include the package and
Node versions, a minimal reproduction, and the error type and status when
available. Remove credentials, customer content, and resource identifiers.

Suspected vulnerabilities do not belong in public issues. Follow
[SECURITY.md](SECURITY.md) and use the private route only when GitHub shows it
as available.

Before 1.0, support covers the current promoted `0.x` line. Repository files
or pre-promotion builds do not create an availability or support promise.
